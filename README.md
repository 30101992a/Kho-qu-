# Kho quỹ Agribank — sơ đồ luồng nghiệp vụ

Mở file `so-do-luong-kho-quy.html` bằng Chrome hoặc Edge.

Trang gồm 15 luồng (kiểm kê, bàn giao thủ kho, ủy quyền, thu chi, vận chuyển, thừa thiếu, chìa khóa, ATM...). Mỗi luồng có sơ đồ và bảng chú thích từng bước, viết đủ trong luồng đó.

Sơ đồ dùng Mermaid: cần mạng lần đầu để tải thư viện.
