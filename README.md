# Kho quỹ Agribank — sơ đồ luồng nghiệp vụ

**Xem online:** https://30101992a.github.io/Kho-qu-/

Mở file `index.html` hoặc `so-do-luong-kho-quy.html` bằng trình duyệt nếu xem offline.

Trang gồm 15 luồng nghiệp vụ kho quỹ. Mỗi luồng có sơ đồ và bảng chú thích từng bước.

Sơ đồ dùng Mermaid: cần mạng để tải thư viện.
